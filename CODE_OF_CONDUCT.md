# Community Code of Conduct

K-Guard MCP is built for people with very different levels of programming experience. Participation should make contributors more capable, not make them afraid to ask.

## Expected behavior

- Be respectful, specific, and patient.
- Critique code and claims, not people.
- Explain unfamiliar terms when they are needed.
- Treat security reports, personal data, and partner context with care.
- Give credit for ideas, tests, documentation, and review work.
- Accept evidence-based correction and change course when facts change.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information or credentials.
- Using real personal data, customer code, or unauthorized targets as demos or fixtures.
- Pressuring maintainers to hide limitations, falsify validation, or weaken release criteria.
- Deliberately disrupting project infrastructure or community spaces.

## Enforcement

Report conduct concerns through the repository's private maintainer contact channel. Do not include raw secrets or personal data. Maintainers may remove content, restrict participation, or take other proportionate action. Reports will be handled as privately as the available project infrastructure permits.

Technical vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public issue.
